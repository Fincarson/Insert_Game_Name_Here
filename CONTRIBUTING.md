# Contributing

Thanks for taking an interest in *Insert Game Name Here*. This is a small game
made for fun, so contributions are welcome but reviewed casually and on my own
time.

## Building

See the "How to Install" section in the [README](README.md). In short: CLion +
CMake, with Allegro5 and LLVM MinGW on your PATH. Open the folder in CLion and
build the default target.

## Reporting a bug or idea

Open an issue. Include what you did, what you expected, and what happened. A
screenshot or short clip helps a lot for anything visual.

## Sending a change

1. Fork and create a branch off `main` (for example `fix/knight-hitbox`).
2. Keep the change focused. One fix or feature per pull request.
3. Match the surrounding style: 4-space indentation, and keep gameplay code in
   the folder it belongs to (`Enemy`, `Weapons`, `Scenes`, and so on).
4. Make sure the game still builds and runs before opening the pull request.
5. Describe what changed and why.

## Assets

Please do not add third-party art, audio, or fonts unless you have the right to
share them. If you are not sure, ask in the issue first.
